📊 Bank Marketing Prediction

A Data Analysis project focused on predicting whether a client will subscribe to a term deposit based on historical marketing campaign data.

🚀 Project Overview

This project analyzes the Bank Marketing dataset from the UCI Machine Learning Repository, which contains data from direct marketing campaigns conducted by a Portuguese banking institution.

The goal is to build a classification model that predicts whether a customer will subscribe to a term deposit (yes/no), helping improve marketing efficiency and targeting.

🎯 Objectives
Perform Exploratory Data Analysis (EDA)
Handle data preprocessing & feature engineering
Train and evaluate classification models
Identify key factors influencing customer conversion
Improve prediction accuracy for marketing decisions
📁 Dataset Description
📌 Source: UCI Bank Marketing Dataset
📊 Records: ~41,000+
🧾 Features: Demographics, campaign details, economic indicators
🎯 Target Variable:
y → Did the client subscribe to a term deposit?

Typical features include:

Age, job, marital status
Education, loans, housing
Contact type, campaign duration
Previous campaign outcomes
